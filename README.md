🌟 About The Project

Employee Salary Calculator is a simple and practical Python-based console application designed to calculate an employee's salary in an easy and organized way.

The project takes an employee's basic salary and calculates important salary components such as HRA, DA, Bonus, Gross Salary, Tax, and Net Salary. It also allows users to view employee details and add new employees through a simple menu-driven system.

This project is specially created for beginners who want to understand how basic Python concepts can be combined to build a useful real-world application. 🚀

✨ Features
Feature	Description
👨‍💼 Employee List	View all available employees
💰 Salary Calculation	Calculate complete salary details
🏠 HRA	Calculate House Rent Allowance
📈 DA	Calculate Dearness Allowance
🎁 Bonus	Calculate employee bonus
🧾 Tax	Calculate tax according to salary
💵 Net Salary	Calculate final salary after tax
➕ Add Employee	Add a new employee
🔄 Menu System	Easy-to-use console menu

💡 Salary Calculation

The program calculates salary using the following structure:

Basic Salary
      ↓
     HRA
      ↓
      DA
      ↓
    Bonus
      ↓
Gross Salary
      ↓
     Tax
      ↓
  Net Salary 💰
📊 Formula

Gross Salary

Basic Salary + HRA + DA + Bonus

Net Salary

Gross Salary - Tax
