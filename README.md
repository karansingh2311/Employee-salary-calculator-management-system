# 💼 Employee Salary Calculator

📊 **Employee Salary Calculator** is a simple Python project designed to calculate an employee's salary based on their basic salary, HRA, DA, bonus, and tax deductions. The project provides a simple menu-based system where users can view employees, calculate salary details, and add new employees.

### ✨ Features

* 👨‍💼 Display employee details
* 💰 Calculate basic and gross salary
* 🏠 Calculate HRA
* 📈 Calculate DA
* 🎁 Calculate bonus
* 🧾 Calculate tax deductions
* 💵 Calculate final net salary
* ➕ Add new employees
* 🔄 Menu-driven program

### 🛠️ Concepts Used

This project is created using basic Python concepts such as **Lists, Functions, For Loop, While Loop, If-Else, and Nested If-Else**. It is a beginner-friendly project that helps in understanding how different Python concepts can be combined to create a practical application.

### 🎯 Purpose

The main purpose of this project is to practice Python programming through a real-life **Employee Salary Management** example. It is suitable for beginners who are learning Python and want to understand functions, loops, lists, and conditional statements through a practical project.
